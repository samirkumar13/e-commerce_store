# SSH Key Setup Guide (Windows)

Since you are currently using a password, follow these steps to generate a secure SSH key and "protect" it with a passphrase.

## 1. Generate a New Key
Open **PowerShell** on your computer and run:

```powershell
ssh-keygen -t ed25519 -C "samir@quriontech"
```

1.  **File location:** Press **Enter** to accept the default (`C:\Users\Samir\.ssh\id_ed25519`).
2.  **Passphrase:** Enter a strong password/sentence here. **This is how you "protect" the key.**
    *   *If someone steals your key file, they still can't use it without this passphrase.*

## 2. Copy Key to VPS
Run this command from **PowerShell** to automatically upload your new public key to the server.
*Replace `password` with your actual VPS password when asked.*

```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh samir@31.97.186.83 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys"
```

## 3. Test the Key
Open a **new** PowerShell window and try to connect:

```powershell
ssh samir@31.97.186.83
```

*   It should **NOT** ask for your VPS user password.
*   It **SHOULD** ask for the **Passphrase** you created in Step 1.

## 4. (Optional) Disable Password Login
Once you confirm the key works, you can disable password login for better security.

1.  Login to VPS: `ssh samir@31.97.186.83`
2.  Edit config: `sudo nano /etc/ssh/sshd_config`
3.  Find `PasswordAuthentication` and change `yes` to `no`.
4.  Save (`Ctrl+O`, `Enter`) and Exit (`Ctrl+X`).
5.  Restart SSH: `sudo systemctl restart ssh`

## 5. Backup (Crucial!)
Copy the file `C:\Users\Samir\.ssh\id_ed25519` (the one *without* .pub) to a USB drive and put it in a safe place.
